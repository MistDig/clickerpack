# IRONLINE resource pack

Public resource pack downloads for IRONLINE / ClickerxD.

Minecraft Java 1.21.11, 26.2 and 26.3 shader stages are included. The server provides a versioned HTTPS download URL and validates the pack using SHA1.

Current pack SHA1: `830a3fc01a6761570f790dab6591450e086b97c9`

`release.zip` is the latest-pack alias. The game uses `main/ironline-<SHA1>.zip` so old advertised hashes continue to resolve and cached downloads remain consistent. Retain hash-named packs when updating.
